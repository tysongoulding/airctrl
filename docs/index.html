Modular Architecture

Built for Speed, Privacy, and Spatial Precision

Every subsystem in airctrl is built as an independent, decoupled Rust crate with strict memory and concurrency guarantees.

Offline Whisper Engine

Runs local Whisper models (consistent with Handy & Meetily) with streaming SHA-256 weight validation. Features mathematical RMS/dBFS VAD gating and p99 latency under 7.24ms.

Shortcut: Ctrl+Spacebar

Radial Dial & App Crawler

Fuzzy window crawler indexes active application accessibility trees (Jaro-Winkler + Levenshtein). Projects open windows onto a 6-sector dynamic radial dial.

Shortcut: Ctrl+Alt

MediaPipe Hand Landmarker

Tracks 21 3D hand landmarks at 30–60+ FPS entirely on CPU with zero GPU requirements. Geometric heuristics detect pointing rays, pinch clicks, and directional swipes.

Gesture: Pinch (d ≤ 0.05) & Point

Camera Privacy Auto-Kill

Monitors Zoom, Teams, Meet, Webex, and Discord. Automatically triggers an atomic CAS kill-switch in <1.0ms to release camera handles upon meeting entry.

Speed: <1.0ms hardware release

Compliance Audio Injection

Programmatically synthesizes and injects statutory recording disclosures (“This meeting is being recorded”) into the active audio stream at ≥ 0.50 volume floor.

Compliance: Statutory Disclosure Injection

Instant LAN Distribution

Built-in Axum daemon on Linux VM generates injection-hardened PowerShell one-liners with dynamic IP discovery for zero-friction Windows dev testing over local WiFi/Ethernet.

Command: irm <ip>/run.ps1 | iex
